What is CallSealSkr?

CallSealSkr is a communication verification dApp for the Solana Seeker phone. It monitors phone calls and SMS messages, creates SHA-256 hashes of communication metadata (phone number, timestamp, duration, direction), and records these hashes on the Solana blockchain as immutable proof that a communication occurred.

Important: CallSealSkr does not record, store, or transmit the actual content of any phone call or SMS message. Only metadata hashes are created and stored on-chain.

Features

Metadata Hashing

Creates SHA-256 hashes of communication metadata — phone number, timestamp, duration, and direction — never the actual content.

Blockchain Proof

Records hashes on the Solana blockchain via the Memo Program as immutable, timestamped proof that a communication occurred.

SGT Free Access

Saga Genesis Token (SGT) holders get free hash recording. Others pay 0.01 SOL or 0.01 SKR per hash.

Seeker Integration

Sign In With Solana, Mobile Wallet Adapter (MWA), and native Seeker device integration.

Important Notice

CallSealSkr creates cryptographic proof that a communication occurred. It does not record call audio, SMS content, or any conversation data. Only SHA-256 hashes of metadata are stored. These hashes are irreversible — the original metadata cannot be reconstructed from the hash. On-chain hashes are immutable and cannot be deleted once recorded.
